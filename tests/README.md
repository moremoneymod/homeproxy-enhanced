# Проверки подписок Re:HomeProxy

Запуск из корня репозитория: `node --test tests/*.test.cjs`.

Тесты читают **исходные функции Re:HomeProxy** из `update_subscriptions.uc`, `homeproxy.uc` и `export_subscription_links.uc`. Проверяются Xray/VLESS/REALITY, WebSocket, фильтрация, произвольные HTTP-заголовки и защита от переноса строки, сборка `vless://`, повторный импорт с сохранением ID, синхронизация Routing URLTest и сохранение узлов при сбое. URL и ключи синтетические; `vpn-sub` не используется.

Node.js запускает извлечённые функции с адаптером различий синтаксиса ucode (`in` для членства в массиве и перебор значений `for (... in ...)`). Поведение UCI и HTTP подменено временной моделью. Это локальные поведенческие тесты, но не компиляция и не исполнение на самом `ucode`.

Перед выпуском нужен интеграционный прогон в среде с настоящими `ucode`, UCI, `ubus` и LuCI: запрос к локальному HTTP-серверу, сохранение `/etc/config/homeproxy`, генерация sing-box JSON и запуск сервиса. Docker daemon на этой машине сейчас не запущен.
